# Left 4 Dead 风格 PvE 第一人称 FPS 游戏 - Valve 风格主界面

基于 **Electron + Three.js + Vite** 构建的经典 Valve / 《求生之路》(Left 4 Dead) 风格客户端主界面。内嵌加载了指定的**砂狼白子突击步枪 3D 模型**（Blue Archive Sunaookami Shiroko's AR）。

---

## 🌟 核心特性

1. **Valve / Source 引擎经典工业与末日恐怖美学**：
   - 粗砺胶片颗粒（Film Grain）与 CRT 扫描线（Scanlines）后处理叠层。
   - 经典 V 社高对比度排版（Teko & Share Tech Mono 字体风格）。
   - 左侧主导航、底部安全区状态栏、警示红/战术蓝/琥珀警报色彩。
   - 战役部署面板（关卡选择、难度等级、幸存者小队编队）。

2. **Three.js 实时 3D 战术安全室场景**：
   - **砂狼白子突击步枪模型**实时加载并放置在战术军械台上。
   - 实时光影渲染：柔和阴影（PCFSoftShadowMap）、战术聚光灯、枪口战术手电筒、旋转红色应急警报灯。
   - 动态悬浮微尘与烟雾粒子系统。
   - 鼠标悬停视差跟随（Parallax Tilt）与摄像机微呼吸晃动。

3. **3D 军械库交互检视（ARMORY & INSPECT）**：
   - 点击主界面的 `03. ARMORY & INSPECT` 即可无缝切换为 360° 自由旋转特写检视视角。
   - 支持鼠标左键拖拽 360 度观察枪械细节，滚轮缩放镜头。
   - 战术手电实时开关控制。
   - 枪机拉栓/检视音效与动画交互。
   - 武器属性卡片（伤害、射速 720 RPM、精准度 88%、射程、弹匣容量）。

4. **Web Audio API 程序化 Valve 音效引擎**：
   - 无需依赖外部音频文件，实时合成纯正 Valve 风格音效：
     - 菜单悬浮轻脆机械滴答声（Tactical Hover Click）
     - 菜单确认沉重金属锁闩声（Heavy Metal Select）
     - 枪械拉栓与上膛机械声（Slide Rack & Bolt Snap）
     - 战备低频氛围无人声（Ambient Drone & Wind）

5. **战役加载过渡模拟**：
   - 点击开启战役或生存模式，即刻呈现求生之路标志性的海报式加载画面、进度条与战术生存提示。

## 🎮 第一人称 PvE 实机战斗系统 (FPS Gameplay)

点击主界面 **`01. CAMPAIGN // 战役模式`** 或 **`02. SURVIVAL // 生存挑战`** -> **`START CAMPAIGN`** 即刻无缝切入游戏：

### 1. 幸存者移动与战斗按键：
- **`WASD`**：前后移动与左右横移
- **`Shift`**：疾跑冲刺（Sprint）
- **`Space`**：跳跃
- **`C`**：下蹲（Crouch，降低脚步并减小受弹面积）
- **`鼠标左键`**：突击步枪全自动开火（连射）
- **`鼠标右键`**：战术机瞄（ADS 瞄准放大，缩紧十字准星提升远距离爆头率）
- **`R`**：战术换弹（Tactical Reload）
- **`V` 或 `Q`**：**枪托推搡（Left 4 Dead 标志性近战格挡）**，击退并硬直正前方 90° 范围内的所有感染者！
- **`F`**：枪载战术手电筒开关（Flashlight）
- **`4` 或 `E`**：使用急救包包扎回血（Medkit）
- **`E`**：场景交互（拾取医疗包、补充弹药箱、引爆炸药桶、开启安全门）
- **`ESC`**：呼出游戏内战术暂停菜单（可重启或返回主界面）

### 2. 核心战斗、物理引擎与打击感系统：
- **高 Star 开源 3D 物理引擎 (Cannon-es)**：
  - 集成知名开源 3D 刚体物理引擎 **`cannon-es`**（2.5k+ Stars）。
  - 场景中的**红色燃油炸药桶**具备真实的圆柱体刚体碰撞与质量模拟。
  - **物理爆炸冲击波（Radial Explosion Impulse）**：射击引爆炸药桶时，物理引擎实时计算空间距离衰减并施加强大的径向爆炸冲量，将周围的刚体、油桶碎片与丧尸炸飞击退！
- **高精度动态准星系统（Dynamic Valve Reticle）**：
  - **多状态动态扩散**：走动、疾跑（Sprint）、跳跃滞空、连续连射时准星平滑扩散，下蹲（Crouch）收紧。
  - **右键机瞄（ADS）精准聚拢**：右键瞄准时外圈准星淡化收缩，中心转变为高精度全息瞄准点。
  - **智能敌方目标锁红**：当准星直接对准受感染的丧尸敌人时，十字准星瞬间变为亮红色（`#ef4444`）预警目标锁定！
- **极致打击感与视觉反馈（Hit Feedback & Combat Juice）**：
  - **屏幕创伤震屏系统（Camera Trauma & Screen Shake）**：射击时产生微幅干脆的后坐震荡，推搡产生前推顿挫，受到近身撕咬或附近油桶爆炸时产生剧烈的创伤性多频屏幕摇晃。
  - **真实抛壳物理（Physical Shell Ejection）**：开火瞬间向枪身右上方抛射出旋转弹跳的黄铜弹壳，具备重力下坠与地面反弹。
  - **高速弹道示踪光束（Bullet Tracers）**：枪口喷射出瞬时高亮弹道光束，直达受击落点。
  - **受击火花与血雾粒子（Sparks & Blood Splatters）**：击中墙体/金属迸发跳跃火花，击中丧尸喷射出血雾粒子，爆头更有大面积肢解血溅。
  - **开源 Tween.js 浮动伤害跳字（Floating Damage Numbers）**：基于 **`@tweenjs/tween.js`**（9.5k+ Stars）实现 3D 投影伤害数字，普通命中显示浮动金黄色伤害，精准爆头触发鲜红跳动的暴击数值（`CRIT!`）！

### 1. 开发预览（Web / Vite）
```bash
npm run dev
```

### 2. 启动桌面端游戏客户端（Electron）
```bash
npm run electron
# 或完整构建并启动：
npm run start
```

### 3. 热键操作
- **F11**：切换全屏模式
- **ESC / 点击返回**：退出 3D 枪械检视模式
- **鼠标左键**：交互/拖拽旋转武器
- **鼠标滚轮**：缩放武器观察距离
